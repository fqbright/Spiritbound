# Spiritbound for Expo Go

This directory contains the Expo/React Native version of the Spiritbound training battle. It targets Expo SDK 57 to match Expo Go 57.0.0.

The battle now uses a portrait game-board layout with a different illustrated arena and Boss portrait for every location, full rectangular character art without circular cropping, ornamental health/action controls, and a curved overlapping hand of illustrated collectible cards. Later encounters contain multiple enemies with separate Health and intent. Drag a card onto a glowing unit to target it; release over open ground to let the game choose a legal target. Harmful cards cannot target the player, and beneficial cards cannot target enemies.

Each turn allows two card plays. Releasing the second card automatically starts every surviving enemy's action, so there is no separate End Turn button. Unplayed cards remain in hand, and each new turn draws only enough cards to refill the hand to five. Enemies visibly lunge at the fox spirit, and the resulting combined damage is applied to Health after Shield.

A run contains five encounters with rising Health, attack strength, and new mechanics: Stone Skin grants Shield, Runic Thorns retaliate against attack cards, Skyfire Precision makes every third attack a visible double-damage Critical Hit, and the final Forge gains Shield, grows stronger each round, and Overloads below half Health. Victories carry the player's remaining Health forward, recover 22 Health, and open an illustrated five-location map where the fox walks toward the next location and its Boss reveal.

Two longer original stereo compositions are included. The 32-second `ember-battle-v2.wav` combat suite changes harmony, percussion density, register, and countermelody across four movements. The 28-second `spirit-path-v2.wav` journey theme uses a slower call-and-response melody with bell, flute, pad, and stereo ambience. The music button in the top bar toggles both tracks.

## Original visual assets

- `assets/battlefield-v1.png`: moonlit shrine battle arena.
- `assets/sentinel-v1.png`: Hollowstone Sentinel portrait.
- `assets/backgrounds/*.png`: four later battlefields and the five-location spirit map.
- `assets/bosses/*.png`: location-specific Boss portraits for encounters two through five.
- `assets/enemies/*-v2.png`: Runic Shard, Ash Raven, and Forge Spark support enemies.
- `assets/cards/*.png`: Strike, Spirit Ward, Foxfire, and Focus Spirit illustrations.
- `assets/card-atlas-v1.png`: source atlas for the four card illustrations.
- `assets/audio/ember-battle-v2.wav`: multi-section looping battle suite.
- `assets/audio/spirit-path-v2.wav`: looping map and journey theme.

These assets were generated with the built-in image generation tool for Spiritbound. Prompts requested wholly original fantasy designs and excluded text, logos, watermarks, and recognizable copyrighted characters.

The music loops are original procedural compositions generated by `scripts/generate-music.mjs` and can be regenerated without external source audio.

## Open on a phone

1. Install **Expo Go** from the App Store or Google Play.
2. Put the phone and this Mac on the same Wi-Fi network.
3. From this directory, run `npm run start:stable`. This clears Metro's cache and displays a QR code.
4. Scan the displayed QR code. On iOS, use the Camera app; on Android, use Expo Go's scanner.

If LAN discovery is blocked by the router, run `npm run start:tunnel`. Tunnel mode requires internet access and can load more slowly.

The live URL is tied to the Mac's current local IP address and only works while the development server is running. Expo Go is a development sandbox; an App Store or Play Store release later requires an EAS/native build.

## Development checks

- `npm run typecheck` validates TypeScript.
- `npm test` runs the combat regression suite.
- `npx expo install --check` validates Expo package versions.

The React Native combat reducer consumes the same `core.json` content file as the Swift implementation. Balance values and English/Simplified Chinese text therefore stay aligned.

## Current development-server limitation

This Mac reaches its file-watcher limit when Metro uses Fast Refresh. The current server runs in CI mode, which serves the app normally but does not automatically reload edits. Restart the server after changing source files, or install Watchman to restore Fast Refresh.

If Metro reports a missing `icon-valuebite.png`, Expo Go has reopened an older local project that previously used the same address and port. Close that project in Expo Go, stop Metro with Ctrl+C, run `npm run start:stable`, and scan the new Spiritbound QR code instead of selecting the old recent-project entry.
